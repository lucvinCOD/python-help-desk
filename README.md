# Python Help Desk

Uma ferramenta de diagnóstico de Help Desk via linha de comando, desenvolvida em Python, para a resolução de problemas básicos de sistema e rede. (A command-line Help Desk diagnostic tool developed in Python for basic system and network troubleshooting.)

## Funcionalidades (Features)
- Informações do computador (Computer information)
- Teste de conectividade (Connectivity test)
- Teste de DNS (DNS test)
- Teste de porta TCP (TCP port tests)
- Verificação de armazenamento (Storage check)

## Tecnologias (Technologies)
- Python
- Bibliotecas padrão (Standard Library): platform, socket, os, getpass, shutil 

## Como executar (How to run)
1. Ter Python instalado (Have Python installed)
2. Clonar o repositório (Clone the repository)
3. Executar `python helpdesk.py` (Run `python helpdesk.py`)
